# Pulley

Pulley moves vector artwork from Adobe Illustrator and Figma into Adobe After Effects as native,
editable shape and text layers. Everything runs locally: no accounts, telemetry or network access.

**Status: milestone 1 (verification and design). Nothing is buildable yet.**
