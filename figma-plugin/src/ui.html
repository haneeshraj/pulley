Pair with the Pulley bridge

Open the Pulley menu (system tray on Windows, menu bar on macOS), choose Pair Figma plugin…, and type the code it shows. Codes work once, for 2 minutes.

Select layers to send.

Help

Send to After Effects imports the selected layers into the active comp (or a new comp the size of the selection) as shape and text layers.

In After Effects, Pull selection in the Pulley panel asks this plugin for the selection while it is open.

The plugin talks only to the Pulley bridge on this computer (127.0.0.1). If it can't connect: start the bridge; in a browser, allow local network access when asked; Safari can't connect to local apps. Save .pulley file works without the bridge: import the file from the Pulley panel in After Effects.

Not imported: image and video fills, effects, angular and diamond gradients. Each skipped item is listed as a warning.
