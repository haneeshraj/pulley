Pull imports the current selection from Illustrator, or from Figma while the Pulley plugin is open there (whichever you used last), into the active comp. In Illustrator or Figma, Push sends a selection here.

If no comp is active, Pulley creates one the size of the artboard or frame.

Not connected? Start the Pulley bridge (it runs in the system tray / menu bar), then click Reconnect.

Figma in Safari or without local network access: save a .pulley file in the plugin and use Import .pulley file here.
